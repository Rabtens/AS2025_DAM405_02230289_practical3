# iris-api

A Dockerised REST service that serves predictions from a scikit-learn
RandomForest classifier trained on the Iris dataset.

## Project structure

```
iris-api/
├── train.py          # trains the model and writes model.joblib
├── app.py             # Flask REST service (health + /predict)
├── model.joblib        # trained model (generated by train.py)
├── requirements.txt   # pinned Python dependencies
├── Dockerfile          # container build instructions
├── .dockerignore        # files excluded from the Docker build context
└── README.md            # this file
```

## Prerequisites

- Python 3.10+
- Docker Desktop or Docker Engine

## 1. Train the model

```bash
pip install -r requirements.txt
python train.py
```

This produces `model.joblib` in the project directory. The model must exist
before the Docker image is built, since `COPY . .` in the Dockerfile bundles
it into the image.

## 2. Build the Docker image

```bash
docker build -t iris-api .
```

## 3. Run the container

```bash
docker run -p 5000:5000 iris-api
```

The service will be available at `http://localhost:5000`.

## 4. Test it

Health check:

```bash
curl http://localhost:5000/
# -> {"status": "ok"}
```

Prediction:

```bash
curl -X POST http://localhost:5000/predict \
  -H "Content-Type: application/json" \
  -d '{"features": [5.1, 3.5, 1.4, 0.2]}'
# -> {"prediction": 0}
```

The `features` array is `[sepal_length, sepal_width, petal_length, petal_width]`
in centimetres. The `prediction` is the Iris class index: `0 = setosa`,
`1 = versicolor`, `2 = virginica`.

## Design notes / best practices applied

- **Slim base image** — `python:3.11-slim` instead of the full `python`
  image, to minimise image size.
- **Layer caching** — `requirements.txt` is copied and installed *before*
  the application code, so `pip install` is only re-run when dependencies
  actually change, not on every code edit.
- **Non-root user** — the container runs as `appuser`, not root, to reduce
  the impact of a potential container compromise.
- **`.dockerignore`** — excludes virtual environments, caches and VCS
  metadata from the build context.

## Stopping the container

```bash
docker ps            # find the container ID
docker stop <id>
```
